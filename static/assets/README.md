# Meridian Screener brand assets

| File | Use |
|------|-----|
| `favicon.svg` | Tab icon (vector, crisp at any size). |
| `logo-mark.png` | Sidebar mark; raster digital-art mark (AI-generated). |
| `logo-wordmark.png` | Docs, slides, or marketing headers (AI-generated). |

Regenerate rasters by replacing the PNGs and bump `dashboard.css` query string in `index.html` if you need cache bust.

The SVG favicon is hand-tuned to match the sea-glass teal palette from `dashboard.css`.

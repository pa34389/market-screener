How to use this table Tap to open or close

Each row is one market we looked at. The computer checked charts with fixed rules. It does not place trades and it is not financial advice.

What each column means

  • Symbol is the short code (like a nickname).
  • Name tells you the real name so you do not mix things up.
  • Setup stage is where we are on a simple checklist. Early stages mean “not ready yet.” Later stages mean “look closer.” The exact words come from the rules engine; hover a pill to see the raw stage code.
  • UI is a small color tag for what price did lately near important zones (watch, sweep, and so on).
  • Grade is how strong the setup looks to the rules. High grades mean the story fits more checks. “Ignore” means the rules say this row is not a focus idea.
  • Bias is whether the bigger picture leans up, down, or sideways.
  • Score is a number score from those same rules.
  • Price is about where price was when we ran.
  • RR is a risk reward style number when the math exists. If you see a dash, the math was missing.

How to use the buttons and tools

  1. Type in the search box to shrink the list to one symbol.
  2. Use the stage dropdown to only show rows in one stage.
  3. Click a column title with arrows to sort. Click again to flip the order.
  4. Press / on your keyboard to jump to the symbol search (when you are not typing somewhere else).
  5. Press Run scan when you want fresh numbers. Big lists can take a while.
  6. Press Refresh to reload the last saved scan from this computer’s log.
  7. Press Export JSON if you want the raw data file.

If something looks wrong, try a new scan. Data can be late or missing because free market feeds have limits.
